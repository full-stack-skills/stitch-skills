# Stitch 转 React Native：深度 FAQ

## Q1：遇到“把 div 原样复制”怎样处理？

换 View，文本独立 Text。处理后验证：无 DOM 元素/浏览器事件且所有文本位于 Text。

## Q2：遇到“认为 RN flex 默认为 row”怎样处理？

显式决定 flexDirection。处理后验证：theme token 来自当前源，Image 有尺寸。

## Q3：遇到“外层 ScrollView 包长 FlatList”怎样处理？

用列表头尾或 View 避免嵌套滚动。处理后验证：检查 iOS/Android 的 safe-area、导航和键盘状态。

## Q4：遇到“AST 通过就称真机通过”怎样处理？

分别记录 AST/类型/平台验收。处理后验证：无 DOM 元素/浏览器事件且所有文本位于 Text。

## Q5：遇到“所有屏幕强制刷新并覆盖缓存”怎样处理？

仅刷新授权范围且保留来源。处理后验证：theme token 来自当前源，Image 有尺寸。

## Q6：多人或多平台交接怎样保持一致？

共享目标 iOS/Android、工程路径、既有导航、主题和刷新范围；按角色分配素材、实现与验收。交接必须带无 DOM 元素/浏览器事件且所有文本位于 Text的证据，以及已完成/待确认状态。不同平台的输出路径与版本分别记录，不能把一个平台成功外推到其他平台。

## Q7：素材含真实客户信息，或者工具缺失怎么办？

先输出本地草案与缺失清单，不运行依赖项。客户字段替换成明确的“演示门店/演示订单”；删除会话、cookie、签名 URL，截图中的个人信息也要脱敏。只检查与任务有关的文件；安装工具前说明具体依赖、范围和影响，已有批准有效。
