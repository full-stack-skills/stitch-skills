# 统一 Stitch 设计规格入口

## Why

页面规格生成与提示词编写由两个技能分别维护，调用方重复编排，模块文档缺少一致的页面、状态、提示词和实施任务追踪。用户已确认整合为 `stitch-design-spec`。

## What Changes

- 新入口合并 PRD→页面规格、规格→提示词、模糊需求润色与精确编辑能力。
- 原两个名称仅保留兼容转交，不维护第二套流程。
- 固定输出模板、来源追踪、状态覆盖、实施任务与可移植完整示例。
- 更新包注册、使用说明及活跃调用方；本地编写无需认证。
- 命名最终遵循上层design、具体UI使用stitch-ui-*、底层MCP的分层；此前15项命名优化之后按用户修正迁移22个具体UI技能。中英文README分类呈现42个主要技能与2个兼容入口，并更新生成器模板。

## Capabilities

### New Capabilities
- `stitch-design-spec`: 本地页面规格与 Stitch 提示词统一编制、校验、交接。

## Impact

影响技能文档、伴随模板/校验工具、技能清单与路由；不改变远程 MCP schema，不安装或发布。此前 Harness 更名涉及 design-skills 的提供方引用适配；本轮15项命名整理仅修改 stitch-skills。
